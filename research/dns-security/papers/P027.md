# P027 — A High-Performance, Scalable Infrastructure for Large-Scale Active DNS Measurements (OpenINTEL)

- Source: IEEE JSAC, 2016 · https://doi.org/10.1109/JSAC.2016.2558918

**Research question:** How can a high-performance, scalable infrastructure for large-scale active DNS measurement be built?
**Method:** System design and implementation (OpenINTEL) that queries large domain populations daily.
**Main findings:** Delivers scalable infrastructure measuring billions of DNS records per day, enabling longitudinal research; the resulting dataset is widely reused.
**Key evidence:** System architecture + operational results.
**Limitations:** Active measurement (not passive/client-side); access terms apply to the dataset.
**Relevance to this project:** OpenINTEL active-DNS dataset infrastructure — data source for own experiments
