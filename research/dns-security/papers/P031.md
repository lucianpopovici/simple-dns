# P031 — CVE-2020-1350 (SIGRed): wormable RCE in Windows DNS Server

- Type/credibility: advisory
- Subtopic: implementation
- Source: CVE/advisory, 2020 · https://nvd.nist.gov/vuln/detail/CVE-2020-1350
- Status: have-meta · summary: verified

**Research question:** (Advisory) Nature and impact of SIGRed, the wormable Windows DNS RCE (CVE-2020-1350)?
**Method:** Vendor/coordinated advisory for a heap-based memory-corruption bug in Windows DNS Server response parsing (dns.exe).
**Main findings:** 17-year-old heap overflow parsing inbound DNS responses; unauthenticated, wormable RCE at SYSTEM; CVSS 10.0. Fix: Microsoft patch (and registry workaround).
**Key evidence:** Vendor advisory + independent analysis.
**Limitations:** Windows-specific, but a direct lesson for bounds-checking in response parsing in any server.
**Relevance to this project:** 17-yr heap overflow parsing DNS responses; CVSS 10 — parser-hardening lesson
