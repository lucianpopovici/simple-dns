# P028 — Tranco: A Research-Oriented Top Sites Ranking Hardened Against Manipulation

- Type/credibility: dataset
- Subtopic: measurement
- Source: NDSS, 2019 · https://doi.org/10.14722/ndss.2019.23386
- Status: have-meta · summary: verified

**Research question:** Are top-site rankings (Alexa, etc.) reliable and manipulation-resistant enough for research use?
**Method:** Analysis of four major rankings on similarity/stability/representativeness/responsiveness/benignness; design of a hardened combined ranking.
**Main findings:** Existing lists are unstable and trivially manipulable (e.g., Alexa rank via a single HTTP request); Tranco provides a more stable, manipulation-resistant, reproducible ranking.
**Key evidence:** Empirical ranking analysis + manipulation experiments.
**Limitations:** Ranking still reflects upstream-list biases; web-popularity proxy.
**Relevance to this project:** Manipulation-resistant domain ranking — sampling frame for measurement
