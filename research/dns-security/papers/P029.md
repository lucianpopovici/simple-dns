# P029 — The Harder You Try, The Harder You Fail: The KeyTrap DoS Algorithmic Complexity Attacks on DNSSEC

- Type/credibility: peer-reviewed
- Subtopic: dnssec
- Source: ACM CCS, 2024 · https://doi.org/10.1145/3658644.3670389
- Status: have-meta · summary: verified

**Research question:** Can algorithmic-complexity attacks on DNSSEC validation cause denial of service?
**Method:** Analysis of validation requirements (evaluating all DNSKEY x RRSIG combinations), construction of crafted malicious responses, and testing against major resolvers.
**Main findings:** A single crafted DNS response can drive up to ~2,000,000x the CPU instruction count, stalling resolvers for as long as ~16 hours; affects all tested major validators; the behaviour is mandated by the DNSSEC spec (umbrella CVE-2023-50387).
**Key evidence:** Proof-of-concept across multiple resolver implementations.
**Limitations:** Mitigations cap validation work / combinations; defense is implementation-side.
**Relevance to this project:** Single packet → ~2M x CPU spike validating crafted DNSKEY/RRSIG combos
