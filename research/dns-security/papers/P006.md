# P006 — Understanding the Impact of Encrypted DNS on Internet Censorship

- Type/credibility: peer-reviewed
- Subtopic: encrypted-dns
- Source: The Web Conference (WWW), 2021 · https://dl.acm.org/doi/10.1145/3442381.3450084
- Status: have-meta · summary: verified

**Research question:** How does encrypted DNS affect Internet censorship — does it help users circumvent it?
**Method:** Measurement of encrypted-DNS reachability/blocking from multiple vantage points against censorship infrastructure.
**Main findings:** Encrypted DNS can help evade DNS-based censorship, but censors retain other levers (SNI, IP blocking) and actively block DoT/DoH; net benefit is partial.
**Key evidence:** Vantage-point measurements of blocking behaviour.
**Limitations:** Censorship environments vary by country/time; vantage coverage limited.
**Relevance to this project:** Encrypted DNS vs censorship — circumvention efficacy
