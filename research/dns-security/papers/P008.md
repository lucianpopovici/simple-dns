# P008 — Oblivious DNS over HTTPS (ODoH): A Practical Privacy Enhancement to DNS

- Type/credibility: peer-reviewed
- Subtopic: encrypted-dns
- Source: PoPETs, 2021 · https://doi.org/10.2478/popets-2021-0085
- Status: have-meta · summary: verified

**Research question:** Can DNS privacy be improved by decoupling client identity from queries without prohibitive cost?
**Method:** Protocol design plus interoperable implementation, a formal model/analysis, and wide-scale performance measurement.
**Main findings:** ODoH hides the client IP from the resolver via an oblivious proxy + encryption; adds only modest latency and is a practical privacy-enhancing replacement for DoH.
**Key evidence:** Deployed interoperable instantiations + formal analysis + latency measurements.
**Limitations:** Security relies on non-collusion between proxy and target; some added latency.
**Relevance to this project:** Decouples client identity from query; formal model + perf
