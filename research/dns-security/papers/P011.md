# P011 — DNS Tunneling: A Deep Learning based Lexicographical Detection Approach

- Type/credibility: preprint
- Subtopic: tunneling-dga
- Source: arXiv, 2020 · https://arxiv.org/abs/2006.06122
- Status: have-meta · summary: verified

**Research question:** Can DNS tunneling and DGA domains be detected from domain-name lexical features using deep learning?
**Method:** LSTM-based DGA classifier and a 1D-CNN classifier trained on lexical characteristics of domain names.
**Main findings:** LSTM reaches ~90% detection; the 1D-CNN detects >97% of DGA domains.
**Key evidence:** Classification metrics on DGA/benign domain datasets.
**Limitations:** Lexical-only — evadable by dictionary/wordlist DGAs; results sensitive to dataset composition.
**Relevance to this project:** LSTM/1D-CNN DGA + tunneling classifier
