# P013 — SoK: A Data-driven View on Methods to Detect Reflective Amplification DDoS Attacks Using Honeypots

- Type/credibility: preprint
- Subtopic: amplification
- Source: arXiv (EuroS&P), 2023 · https://arxiv.org/abs/2302.04614
- Status: have-meta · summary: verified

**Research question:** How effective are honeypot-based methods at detecting reflective amplification DDoS attacks?
**Method:** Systematization-of-knowledge plus data-driven evaluation across ten industry/academic datasets spanning 2019-2023.
**Main findings:** Assesses and compares detection methods, examines a reported 2021-22 drop in amplification attacks, and surfaces methodological gaps/biases in honeypot-based detection.
**Key evidence:** Cross-dataset analysis.
**Limitations:** Honeypot visibility bias; preprint/SoK scope.
**Relevance to this project:** Systematization of amplification-DDoS detection methods
