# P021 — RFC 9250: DNS over Dedicated QUIC Connections (DoQ)

- Type/credibility: standard
- Subtopic: encrypted-dns
- Source: IETF RFC, 2022 · https://datatracker.ietf.org/doc/rfc9250/
- Status: have-meta · summary: verified

**Research question:** (Standard) How should DNS be carried over QUIC?
**Method:** IETF standards specification (DoQ) over dedicated QUIC connections.
**Main findings:** Provides TLS-like confidentiality with QUIC, avoiding TCP head-of-line blocking; privacy similar to DoT, latency closer to UDP.
**Key evidence:** Normative specification.
**Limitations:** Spec, not an evaluation.
**Relevance to this project:** DoQ spec
