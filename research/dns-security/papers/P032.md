# P032 — DNSpooq (CVE-2020-25681..25687): dnsmasq overflow + cache poisoning

- Type/credibility: advisory
- Subtopic: cache-poisoning
- Source: CVE/advisory, 2021 · https://www.kb.cert.org/vuls/id/434904
- Status: have-meta · summary: verified

**Research question:** (Advisory) Nature and impact of DNSpooq in dnsmasq (CVE-2020-25681..25687)?
**Method:** Coordinated advisory covering seven dnsmasq vulnerabilities.
**Main findings:** Two classes: heap buffer overflows in code preparing DNSSEC data for validation, and weak query/reply matching enabling cache poisoning; together allow RCE, DoS, and forged answers. Fix: dnsmasq 2.83.
**Key evidence:** CERT/CC + vendor advisories.
**Limitations:** dnsmasq-specific, but illustrates forwarder parsing + reply-validation pitfalls.
**Relevance to this project:** Forwarder memory corruption + weak query/reply matching → poisoning
